# Gzyms for agents

- **Using Gzyms** (a notification, a setting, a theme, something new on the bar): run `gzyms skill` and follow it. The CLI first (`gzyms notify`, `gzyms set`, `gzyms theme`), a plugin only when the CLI cannot do it. Online: https://gzyms.dev/llms.txt.
- **Changing this repo:** read `CLAUDE.md` and `CONTRIBUTING.md` first. `scripts/check.sh` ends with `ALL GREEN` before a change is done.
- **A bug or an idea:** a [Discussion](https://github.com/zalewskigrzegorz/gzyms/discussions), Problems or Ideas. Issues are the to-do list. Write it for the user to post, never post it yourself.
